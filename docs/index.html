A simple Markdown editor for your desktop.

MarkPad is a small Markdown reader and editor for Mac, Windows and Linux. It makes .md files feel like ordinary text files. Open one and it's already formatted, so you can read it, review it and change it straight away, without a heavy app or a paywall between you and a quick edit.

Mac, Apple silicon 3.6 MB Mac, Intel 3.7 MB Windows 3.3 MB Linux .deb Linux .rpm

Windows 10 and later, macOS 13 and later. The .deb is for Debian 12 and Ubuntu 22.04 on, the .rpm for Fedora. Not sure which Mac you have? Apple menu, then About This Mac. Anything from 2020 on is almost certainly Apple silicon.

Nothing is signed, so the first launch needs one extra step on macOS and Windows: on macOS right-click the app and choose Open, on Windows click More info then Run anyway. Linux just installs. If it won't open at all, troubleshooting has the message you're looking at and what to do about it.

Quick to install

The Windows installer is 3.3 MB and the Mac ones are about the same. MarkPad uses the web view your computer already has, so there's little to download.

Native

Feels like your other apps

MarkPad uses the standard window on macOS and Windows, so snapping, minimising and switching between apps all work as you'd expect.

Ordinary .md files

Everything you write is saved as a standard GitHub-flavoured Markdown file on your own disk, so any other editor can open it.

##What's in it

Here's what v0.1 can do.

  • Formatted from the start

    Files open as formatted text and you edit them right there, so you never have to switch out of code view to see the result. If you want the raw Markdown, one command shows it.

  • Command palette

    Ctrl/⌘+K opens a list of every command. The menus have them too.

  • Outline spine

    A 26px strip down the left edge with one tick per heading. It shows the shape of the document and takes far less room than a sidebar.

  • Tabs that come back

    Open several files at once, or drag them in. The tabs you had open come back the next time you start the app.

  • Popover previews

    Tables, LaTeX and Mermaid diagrams show up in a popover next to the cursor. There's also a full preview pane, which is off by default.

  • Export to HTML and PDF

    Export uses your system's print engine, so you don't need Pandoc or a LaTeX install.

  • Keeps your line endings

    It detects CRLF or LF when you open a file and saves it the same way. The status bar shows which one it is. A UTF-8 BOM is kept too.

  • Themes that follow the OS

    Light and dark, switching when your system does. Diagrams and code blocks switch with it.

##Performance limits

These are the limits the project sets itself. Only the installer size is checked automatically on every build. The rest are measured, and a change that goes over one gets fixed or dropped.

##What it won't do

We left these out to keep MarkPad a simple text editor.

  • ✕ Note-taking features such as backlinks, tags and graph views
  • ✕ Accounts, cloud sync or subscriptions
  • ✕ Analytics, crash reporting or telemetry
  • ✕ Markdown syntax that only works in MarkPad
  • ✕ A bundled Chromium, or a runtime you have to install yourself

Try it

MarkPad is a few megabytes and free to use. Your files stay as plain text, so you can stop using it whenever you like.
