Installing · Windows · macOS

When it won't open

MarkPad isn't code signed, because a certificate costs money every year and this is free. Both operating systems notice, and both say something alarming about it. Here is what each message means and how to get past it.

  • "MarkPad is damaged"
  • "Apple cannot check it"
  • Wrong Mac build
  • "Windows protected your PC"
  • Antivirus removes it
  • Blank window on Windows
  • Double-click opens something else

##macOS

Anything downloaded through a browser gets a quarantine flag. Gatekeeper checks that flag on first launch and refuses apps it can't trace back to a paid developer account, which is every build here.

"MarkPad is damaged and can't be opened"

What macOS says“MarkPad” is damaged and can’t be opened. You should move it to the Bin.

Nothing is damaged. It's the message Gatekeeper gives for a quarantined app with no signature, and it's the same wording it would use for a genuinely corrupt download, which is unhelpful of it.

Drag MarkPad into Applications first, then right-click it and choose Open. Choose Open again in the dialog that follows. Double-clicking gives you the dead end instead of the dialog, so the right-click matters.

If the message keeps coming back, clear the flag yourself in Terminal:

xattr -dr com.apple.quarantine /Applications/MarkPad.app

That command removes the download flag from one app you chose to install. Run it on things you trust and nothing else.

"Apple cannot check it for malicious software"

What macOS says“MarkPad” can’t be opened because Apple cannot check it for malicious software.

Same cause, softer wording. macOS shows this one when the app is unsigned but not quarantined as hard.

  1. Right-click MarkPad in Applications and choose Open.
  2. Choose Open in the dialog.

If there's no Open button, try to launch it once, then go to System Settings, Privacy & Security, scroll to the Security section and click Open Anyway next to the note about MarkPad. The button only appears for about an hour after the blocked launch.

macOS remembers the decision, so this is a first launch thing and not something you do again.

It opens and immediately quits, or won't install at all

Usually the wrong dmg for the chip. There are two: aarch64 for Apple silicon and x64 for Intel.

Check yours in the Apple menu, then About This Mac. A Mac from 2020 or later is almost certainly Apple silicon. Download the other dmg, drag it over the copy in Applications and replace it.

##Windows

The installer is per user, so it never asks for an admin password. What it does trip is SmartScreen, which flags any installer it hasn't seen enough copies of.

"Windows protected your PC"

What Windows saysWindows protected your PC. Microsoft Defender SmartScreen prevented an unrecognised app from starting.

Unrecognised publisher, not detected malware. Signed installers from small projects get this too until enough people have run them.

  1. Click More info in the dialog.
  2. Click Run anyway.

If your browser blocked the download before you got that far, open the downloads list and choose Keep on the file.

Your antivirus deletes the installer

Some scanners quarantine unsigned installers on sight, so the file vanishes from Downloads with no message.

Check the quarantine list in your antivirus and restore it from there, or add the file to its exclusions before downloading again. Only download the installer from the releases page, where every file is built by the project's own CI.

Windows can also block a file it thinks came from the internet. Right-click the exe, choose Properties, and tick Unblock at the bottom of the General tab if it's there.

The window opens blank, or an error mentions WebView2

MarkPad draws its interface with the WebView already on your machine rather than shipping a copy of Chromium, which is how the installer stays under 4 MB. Windows 11 and current Windows 10 have it. Stripped LTSC images and some Windows Server builds don't.

Install the Evergreen Runtime from Microsoft's WebView2 page, then start MarkPad again. It's a Microsoft download, and it's the same component Office and Teams use.

"This app can't run on your PC"

The build is 64-bit x86. It won't start on a 32-bit install, and it won't start on an Arm device such as a Surface Pro X or a Snapdragon laptop.

There's no Arm build today. If you want one, say so on an issue and it'll help work out whether it's worth doing.

##Both platforms

Double-clicking a .md file still opens the old editor

Installing MarkPad doesn't take the file association off whatever had it, which is deliberate. You can hand it over whenever you want to.

  • Windows: right-click a .md file, Open with, Choose another app, pick MarkPad and tick always use this app.
  • macOS: right-click a .md file, Get Info, pick MarkPad under Open with, then click Change All.

There's no Linux download

The .deb and .rpm builds exist and the app runs, but they aren't released yet. They ship once they've had enough real use on a real desktop to be worth calling a release.

You closed a file and lost what you'd typed

There's no autosave and no crash recovery, so the dialog asking about unsaved changes is the only thing standing between you and lost work. Every route out of the app shows it, including closing a tab and quitting.

Save with Ctrl+S or ⌘+S as you go. Leaving autosave out is a decision rather than an oversight, and it's the reason that dialog is treated as seriously as it is.

Still stuck

Open an issue with your operating system, the version of MarkPad and what the message said, word for word. That's usually enough to work out what happened.
