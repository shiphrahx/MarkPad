  • One binary, two chromes

    Traffic lights on macOS, caption buttons on Windows. Same Rust shell underneath — flip the toggle above to compare.

  • Command palette

    Every command has one home. Windows users get parity without a Mac menu bar.

  • Outline spine

    Heading ticks in a 26px rail. You get structure without giving up a sidebar.

  • Preview on demand

    Popovers for tables, LaTeX and Mermaid. A full pane exists, but it's off by default.

  • Honest status bar

    Words, position, encoding, line endings. CRLF vs LF matters the moment Windows joins.

  • Export built in

    HTML and PDF ship in the box, via the system print engine. No Pandoc install required.
